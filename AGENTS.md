# WriteToSee Developer Instructions

## Planning and Execution Rules
*   **Bypass Planning Mode:** You must bypass planning mode by default. Do NOT create implementation plans, task checklists (e.g. `task.md`), or walkthrough artifacts (e.g. `walkthrough.md`) at the start of any conversation.
*   **Direct Execution:** Proceed directly to editing files, running commands, and implementing requested changes. 
*   **Exceptions:** Only create an implementation plan or task checklist if the user explicitly asks for one (e.g. "please make a plan").
